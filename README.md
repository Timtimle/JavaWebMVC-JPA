# JavaWebMVC-JPA

A Java web application built with MVC and three-tier architecture, using JPA and Hibernate for database persistence.

## Tech Stack
Java 17 · Jakarta EE · Hibernate ORM · Maven · SQL Server · Tomcat 11

## Features
- User authentication and registration
- Session and cookie-based authentication
- Remember Me functionality
- Category CRUD operations
- JPA-based data persistence

## Build
```bash
mvn clean package
```
